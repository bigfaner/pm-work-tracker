AI Copilot 对话助手 — UI 原型

全局浮动 overlay，对话 + 卡片混合模式。本原型模拟既有「事项清单」宿主页 + Copilot overlay，演示 8 个组件的关键状态。

⚠ 本功能为全局 overlay，不新建页面。原型用左下角「状态切换器」在面板内切换卡片状态，仅供评审；实际产品中 AI 按对话实时推送卡片。

UF-9 意图回执（文本）· 写操作前置

trace 完成后，AI 用自然语言简单回执用户意图（不做字段列表卡片）。用户确认"理解正确"后进入主动澄清阶段；选"我要调整"则聚焦输入框预填用户原文。

intent-echo

UF-3 写卡片 · 表单（UF-9 收齐信息后）

意图回执 → 主动澄清 Q&A → 用户回答 → AI"信息已收齐" → 表单卡片渲染。所有必填字段已通过对话收齐，无 required-highlight 高亮。

write-prefilled

UF-3 写卡片 · 预校验失败

状态机预校验不通过，validTransitions chips 列合法目标。

validation

UF-3 写卡片 · 提交失败

后端字段校验错误就近展示 + 顶部错误条 + 当前 turn 标"重试 N 次"（历史回看不显示）。

submit-failed

UF-3 写卡片 · 已提交折叠 + AI 跟进

表单折叠为单行 summary（点击展开只读字段）+ AI 跟进消息衔接下一轮。

committed

UF-3 写卡片 · 已丢弃

表单折叠为"⊘ 已丢弃 · title"单行，保留在 transcript 避免孤儿用户输入。

discarded

UF-3 写卡片 · 权限不足

canSubmit=false，卡片体替换为权限提示，无提交控件。

permission

UF-3 diff 确认内联

对话补充增量变更，内联展示 old→new（无二级浮窗），应用/丢弃由输入区选项组承载。

diff-overlay

UF-4 查询结果 · 多记录折叠 + 点击独立展开

多记录返回时全部折叠（核心 8 字段）；点击任意卡片头行就地展开为紧凑详情（追加描述/创建人/子任务/最近变更等 ~4 字段），独立 toggle、不互斥，不跳转、不弹窗。

query

UF-4 查询结果 · 单记录自动展开

单记录返回时直接渲染为展开态（~12 字段），用户无需点击即可看到完整紧凑详情。

query-single

UF-4 查询结果 · ItemPool/Milestone/ProgressRecord

同一 schema 驱动剩余 3 实体的 result-card 渲染（含展开态追加字段：背景/预期产出/子事项列表/上次进度等），演示扩展性。ProgressRecord 的 title 由 subItem.title 派生（value_from）。

query-entities

UF-5 歧义消解

多候选在输入区选项组呈现，键盘 ↑↓+Enter 选择。

disambiguation

UF-6 超时/降级

warning-bg 提示卡 + 传统表单快捷入口。

fallback

思考中 + 流式骨架

三点跳动 + border-dashed 卡片骨架增量填充。

thinking

UF-8 Agent 过程 · 成功自动折叠

流式思考 → 计划 → 操作，全部 ✓ 后约 600ms 自动折叠为头部摘要。

agent-trace
