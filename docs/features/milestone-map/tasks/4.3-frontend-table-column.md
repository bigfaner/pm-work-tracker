# 4.3: Table view milestone column (UF-6)

## Description
Add a "里程碑" column to the existing TableViewPage, positioned between "标题" and "优先级" columns. Supports sorting by milestone name and filtering by milestone.

## Reference Files
- docs/features/milestone-map/ui/ui-design.md — Component: 表格视图里程碑列（UF-6）

- docs/features/milestone-map/prd/prd-ui-functions.md — UF-6
- frontend/src/pages/TableViewPage.tsx — target file

## Acceptance Criteria
- [ ] "里程碑" column renders between "标题" and "优先级" (w-32); assigned shows milestone name (`text-secondary`); unassigned shows "-" (`text-tertiary`)
- [ ] Column header sorting: asc (default, alphabetical by name, unassigned at end) and desc (reverse alphabetical, unassigned at end)
- [ ] Column header filtering: dropdown with "全部" / "未分配" / milestone names; filters rows by milestoneKey
- [ ] Deleted milestone shows "—"; data load failure shows "—" without blocking table render
