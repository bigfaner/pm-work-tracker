## Conventions Established

- Milestone dialog components follow the externalized form state pattern (form + onFormChange + isPending) established by CreateMainItemDialog
- Milestone status variant mappings reuse existing badge system rather than introducing new visual variants
- API module naming: listXxxByMapApi vs listXxxByTeamApi to disambiguate scope-specific list endpoints
- Transitions API functions unwrap envelope responses to plain arrays, matching getMainItemTransitionsApi pattern
- Test mocking: use vi.mock for API modules instead of MSW when React Query timer interactions are involved; avoid vi.useFakeTimers with React Query
- Navigation: use useNavigate + onClick rather than Link wrapper when stopPropagation is needed on child elements
