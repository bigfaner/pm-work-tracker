# 2.3: MainItem repository milestone methods

## Description
Add 4 milestone-related methods to the existing MainItemRepo interface and implement them in the GORM implementation. These methods support milestone-MI binding: find by milestone, count by milestone, and batch clear operations for cascade unbinding.

## Reference Files
- docs/features/milestone-map/design/tech-design.md — Interfaces (MainItemRepo MODIFIED), Business Rules (BR-1 cascade logic)
- backend/internal/repository/main_item_repo.go — existing interface
- backend/internal/repository/gorm/main_item_repo.go — existing implementation

## Acceptance Criteria
- [ ] `FindByMilestoneKey(ctx, milestoneBizKey)` returns all MainItems where `milestone_key = milestoneBizKey` (not deleted)
- [ ] `CountByMilestoneKey(ctx, milestoneBizKey)` returns correct count of associated MIs
- [ ] `ClearMilestoneKeyByMilestone(ctx, milestoneBizKey)` sets `milestone_key = NULL` for all items under a single milestone (used by milestone cancel/delete)
- [ ] `ClearMilestoneKeyByMap(ctx, milestoneBizKeys)` batch-clears `milestone_key` for all items under multiple milestones (used by map cancel/delete)
