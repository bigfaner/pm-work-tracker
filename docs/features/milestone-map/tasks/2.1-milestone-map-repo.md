# 2.1: MilestoneMap repository (interface + GORM implementation)

## Description
Implement the MilestoneMapRepo interface and its GORM implementation for MilestoneMap CRUD, filtering (name/assignee/status), and soft delete. Follows existing repository patterns (BaseModel, NotDeleted scope, FindById, UpdateFields).

## Reference Files
- docs/features/milestone-map/design/tech-design.md — Interfaces (MilestoneMapRepo), Architecture Layer Placement
- backend/internal/repository/gorm/ — existing repo implementations for pattern reference

## Acceptance Criteria
- [ ] `MilestoneMapRepo` interface in `repository/milestone_map_repo.go` defines all 6 methods: Create, FindByID, FindByBizKey, Update, List, SoftDelete
- [ ] `milestoneMapRepo` GORM implementation in `repository/gorm/milestone_map_repo.go` persists MilestoneMap with correct field mapping
- [ ] `FindByID`/`FindByBizKey` returns correct model or wrapped not-found error
- [ ] `List` with filter (name LIKE, assignee equality, status equality) and pagination returns `PageResult[MilestoneMap]`
- [ ] `SoftDelete` sets `deleted_flag=1` and `deleted_time=now` using GORM scope
