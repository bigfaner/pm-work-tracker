# 3.4: Milestone detail panel component (UF-3 + UF-3a)

## Description
Build the MilestoneDetailPanel slide-over panel for viewing and managing a single milestone. Includes status switching, MI list with unbind, quick add MI, and delete confirmation. Also handles the QuickAddMainItemDialog (UF-3a) by reusing CreateMainItemDialog with milestone pre-filled.

## Reference Files
- docs/features/milestone-map/ui/ui-design.md — Component: 里程碑详情面板（UF-3）, Quick Add MainItem Dialog（UF-3a）
- docs/features/milestone-map/ui/prototype/milestones.html — interactive prototype
- docs/features/milestone-map/design/tech-design.md — Business Rules (BR-1, BR-3, BR-4, BR-5)
- frontend/src/components/shared/StatusTransitionDropdown.tsx — status switch component
- frontend/src/components/shared/ConfirmDialog.tsx — delete confirmation
- frontend/src/components/shared/ProgressBar.tsx — progress display

## Acceptance Criteria
- [ ] Panel slides in from right (w-360px, translate-x 300ms ease-out) when milestone node clicked; closes on overlay click, Escape, or × button with focus returning to triggering node
- [ ] Displays: name, description area (row 1: label + StatusTransitionDropdown + edit btn; row 2: text with line-clamp:6 + Tooltip), expected end date, progress (ProgressBar + percentage), related MI list
- [ ] Status switch via StatusTransitionDropdown shows only valid transitions; parent map terminal → no dropdown options (BR-5)
- [ ] MI list: hover shows × unbind button; click × triggers API + undo toast (5s); terminal MI hides × button (BR-3); cancelled milestone hides list and "+ 添加" button
- [ ] Quick add: clicking "+ 添加" opens CreateMainItemDialog with milestone field pre-filled and disabled (UF-3a)
- [ ] Delete button visible only for not_started/cancelled states (BR-4); ConfirmDialog shows "确定删除里程碑 [名称]？关联的 X 个事项将解除绑定"
