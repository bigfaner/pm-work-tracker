# 1.2: Models, Status Defs, Permission Codes, DTOs, VOs

## Description

Create Go struct models (MilestoneMap, Milestone), status definitions and transition maps, permission codes, request/response DTOs, and VO conversion functions. All backend foundational types needed by the API layer.

## User Stories

- Story 1: "名称必填 1-100 字符" (DTO binding tags enforce this)
- Story 3: "状态 Badge 下拉仅显示合法转换" (transition map defines valid transitions)
- Story 5: "completed → cancelled 可用, cancelled 无选项" (status terminal flags)

## Implementation Notes

- MilestoneMap transition map: planning→reviewed, reviewed→ready|planning, ready→executing|reviewed, executing→completed|ready, completed→terminal
- Milestone transition map: not_started→in_progress|cancelled, in_progress→completed|cancelled, completed→cancelled, cancelled→terminal
- VO computed fields (MilestoneCount, ItemCount, etc.) are populated by service layer at query time, not in the VO constructor itself
- Permission codes for `pm` role: all 4 milestone codes; for `member` role: only `milestone:read`
