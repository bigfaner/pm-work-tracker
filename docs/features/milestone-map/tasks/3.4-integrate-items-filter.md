# 3.4: Integrate: Items Page Milestone Filter (UF-4)

## Description

Add milestone filter dropdown to the items list page (/items). Filter bar gets a new "里程碑" selector beside existing status and assignee filters. Each MI row shows its milestone name as a tag.

## Reference Files

- `design/tech-design.md` — Integration Spec: MilestoneFilter → /items page (UF-4)
- `ui/ui-design.md` — Component "事项清单页里程碑筛选" (UF-4)
- `ui/prototype/items.html` — Prototype with milestone filter
- `frontend/src/pages/ItemViewPage/` — Target page
- `prd/prd-ui-functions.md` — UF-4 specification

## Acceptance Criteria

- [ ] Milestone filter dropdown added to items page filter bar, positioned after existing filters
- [ ] Dropdown options: all team milestones (excluding cancelled) + "全部" + "未分配"
- [ ] Selecting a milestone filters MI list to only those with matching milestoneKey
- [ ] Selecting "未分配" shows only MIs with null milestoneKey
- [ ] MI list rows show milestone name tag (or nothing if unassigned)
- [ ] Filter resets when switching teams
- [ ] Component works correctly in isolation (build task)

## User Stories

- Story 6: "我在事项清单页筛选该里程碑 → 列表只显示属于该里程碑的事项"

## Implementation Notes

- Integration task: wire the filter component into the existing ItemViewPage
- Data source: `listMilestonesByTeamApi(teamBizKey, { excludeCancelled: true })`
- Filter value passed to existing `listMainItemsApi` as a query param
