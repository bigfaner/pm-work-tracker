# 1.2: Schema: ALTER pmw_main_items add milestone_key column

## Description
Add `milestone_key` (BIGINT nullable) column to `pmw_main_items` table with a B-tree index, in both MySQL and SQLite dialects. This column references `pmw_milestones.biz_key` without a DDL foreign key constraint.

## Acceptance Criteria
- [ ] MySQL ALTER adds `milestone_key BIGINT` nullable column to `pmw_main_items`
- [ ] SQLite ALTER adds `milestone_key INTEGER` column to `pmw_main_items`
- [ ] Index `idx_main_items_milestone_key` created on `milestone_key`
