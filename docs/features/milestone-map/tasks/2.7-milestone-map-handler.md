# 2.7: MilestoneMap handler (API endpoints)

## Description
Implement MilestoneMapHandler with 7 API endpoints following existing handler patterns (panic-on-nil constructor, middleware context extraction, ShouldBindJSON/Query, VO conversion in `buildXxxVOs`).

## Reference Files
- docs/features/milestone-map/design/tech-design.md — Handler Pattern, Router Wiring (Route Registration), Permission-to-Operation Mapping
- docs/features/milestone-map/design/api-handbook.md — MilestoneMap Endpoints (Create, List, Get, Update, Delete, ChangeStatus, AvailableTransitions)
- backend/internal/handler/item_pool_handler.go — pattern reference

## Acceptance Criteria
- [ ] `Create` handler binds `MilestoneMapCreateReq`, calls service, converts to `MilestoneMapVO` with creator/assignee name enrichment, returns 201
- [ ] `List` handler binds query filters (`MilestoneMapFilter`) + pagination, returns `PageResult[MilestoneMapVO]` with computed fields
- [ ] `Get` handler resolves `:mapId` via `ParseBizKeyParam`, returns single `MilestoneMapVO` with full enrichment
- [ ] `Update` handler binds partial `MilestoneMapUpdateReq`, calls service, returns updated `MilestoneMapVO`
- [ ] `Delete` handler calls service (BR-4 enforced), returns `{ "message": "deleted" }`
- [ ] `ChangeStatus` + `AvailableTransitions` handlers correctly proxy to service with route param resolution

## User Stories
- Story 1: PM 创建里程碑图 (Create)
- Story 2: PM 编辑里程碑图信息 (Update)
- Story 3: PM 删除里程碑图 (Delete)
- Story 4: PM 切换里程碑图状态 (ChangeStatus + AvailableTransitions)
