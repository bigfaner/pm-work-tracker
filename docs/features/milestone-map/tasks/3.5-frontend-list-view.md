# 3.5: MilestoneMap list view and card components (UF-1 level 1)

## Description
Build MilestoneMapList and MilestoneMapCard components for the list view (UF-1 first level). Shows card grid with filtering (name search, assignee, status), empty/loading/error states, and dashed create card.

## Reference Files
- docs/features/milestone-map/ui/ui-design.md — Component: 里程碑图列表视图（UF-1 第一级）, Status Badge 颜色映射
- docs/features/milestone-map/ui/prototype/milestones.html — interactive prototype
- docs/features/milestone-map/prd/prd-ui-functions.md — UF-1 Data Requirements, States, Validation Rules
- frontend/src/components/shared/ProgressBar.tsx — progress display

## Acceptance Criteria
- [ ] Card grid (`grid grid-cols-[repeat(auto-fill,minmax(340px,1fr))]` gap-4) renders with 4-line layout per card: row 1 name+StatusBadge, row 2 milestone/item counts + assignee (space-between), row 3 date span + overall progress bar + %, row 4 milestone node thumbnail
- [ ] Name search (Input, debounce 300ms, client-side fuzzy), assignee filter (Select, team members), status filter (Select, all 6 states) work for client-side filtering; reset button clears all filters
- [ ] Empty state shows "暂无里程碑图" centered + create button (if milestone:create permission); loading shows 3 skeleton cards; error shows "加载失败，请重试" + retry button
- [ ] Card click navigates to `/milestones/:mapId`; dashed create card (`border-dashed`) triggers CreateMilestoneMapDialog
- [ ] Hover effect: card border highlight + shadow

## User Stories
- Story 9 (列表视图部分): PM 通过里程碑图查看阶段进展
- Story 14: 不同角色查看里程碑进展 (read-only: hide create button and dashed card)
