# 2.4: MilestoneMap service (CRUD + status transitions + completion)

## Description
Implement MilestoneMapService interface and implementation with full CRUD, status transitions (enforcing BR-2, BR-4, BR-6), available transitions (BR-2 filtering), and computed fields (overallProgress, milestoneCount, itemCount).

## Reference Files
- docs/features/milestone-map/design/tech-design.md — Interfaces (MilestoneMapService), Available Transitions (服务层), Business Rules (BR-2, BR-4, BR-6), Computed Fields
- docs/features/milestone-map/prd/prd-spec.md — MilestoneMap 状态机转换规则

## Acceptance Criteria
- [ ] `Create` validates fields, generates BizKey, sets status to `planning`, returns created MilestoneMap
- [ ] `Update` applies partial updates (nil fields skipped), validates date range if both provided
- [ ] `Delete` enforces BR-4 (only planning/reviewed/ready), cascades: soft-delete all milestones + clear all MI milestone_keys in one transaction
- [ ] `ChangeStatus` validates transition via `IsValidTransition`, enforces BR-2 (completed requires all milestones terminal), BR-6 (cancelled cascades: cancel non-terminal milestones + unbind all MIs)
- [ ] `AvailableTransitions` returns `GetAvailableTransitions` list, filtered by BR-2 (removes `completed` if milestones not all terminal)
- [ ] `calcOverallProgress` computes average MI completion across all milestones; `List` enriches each map with computed milestoneCount, itemCount, overallProgress

## User Stories
- Story 1: PM 创建里程碑图 (Create)
- Story 2: PM 编辑里程碑图信息 (Update)
- Story 3: PM 删除里程碑图 (Delete + BR-4)
- Story 4: PM 切换里程碑图状态 (ChangeStatus + BR-2)
