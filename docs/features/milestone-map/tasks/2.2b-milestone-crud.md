# 2.2b: Milestone Basic CRUD

## Description

Implement the 5 basic CRUD endpoints for Milestone: Create, ListByMap, ListByTeam, Get, Update (with 409 conflict handling).

## Reference Files

- `design/api-handbook.md` — Milestone Create, List, Get, Update endpoints
- `backend/internal/service/main_item_service.go` — Service pattern

## Acceptance Criteria

- [ ] `service/milestone_service.go`: Interface + implementation with Create, Get, GetByBizKey, ListByMap, ListByTeam, Update
- [ ] `handler/milestone_handler.go`: Create, ListByMap, ListByTeam, Get, Update handlers
- [ ] Create: name validation (1-100 chars), expectedEndDate required, default status `not_started`, validate parent map exists
- [ ] ListByMap: non-paginated, ordered by expected_end_date ASC
- [ ] ListByTeam: excludeCancelled filter (default true), for UF-4/5/6
- [ ] Get: by bizKey, 404 if not found
- [ ] Update: partial update, 409 conflict on concurrent edit (use dbUpdateTime optimistic locking)
- [ ] Routes: POST under milestone-maps/:mapId, GET list by map, GET list by team, GET detail, PUT update
- [ ] `just test` passes

## Implementation Notes

- Update 409: compare request dbUpdateTime with current record's dbUpdateTime, return 409 if mismatch
- ListByTeam is used by frontend selectors/filters — keep response lean
- Create must validate parent MilestoneMap exists and is not deleted
