# 3.2: Create/Edit MilestoneMap dialog component (UF-7)

## Description
Build the CreateMilestoneMapDialog component for creating and editing milestone maps. Uses Dialog, Input, Textarea, MemberSelect, and date picker components from the project design system.

## Reference Files
- docs/features/milestone-map/ui/ui-design.md — Component: 创建/编辑里程碑图弹窗（UF-7）
- docs/features/milestone-map/ui/prototype/milestones.html — interactive prototype
- docs/features/milestone-map/design/tech-design.md — DTO Definitions (MilestoneMapCreateReq, MilestoneMapUpdateReq)
- frontend/src/components/ui/dialog.tsx — Dialog component
- frontend/src/components/shared/MemberSelect.tsx — member selector

## Acceptance Criteria
- [ ] Dialog renders form with name (Input), assignee (MemberSelect), plan start date (DatePicker), expected end date (DatePicker), description (Textarea 160px, resize: vertical)
- [ ] Create mode: title "创建里程碑图", empty form; validation enforces required fields (name, assignee); on success calls `createMilestoneMap` API
- [ ] Edit mode: title "编辑里程碑图", form pre-fills current values; on success calls `updateMilestoneMap` API
- [ ] Submitting state: confirm button shows loading, all inputs disabled
- [ ] Date validation: expected end date must not be earlier than plan start date; form shows error text

## User Stories
- Story 1: PM 创建里程碑图 (create mode)
- Story 2: PM 编辑里程碑图信息 (edit mode)
