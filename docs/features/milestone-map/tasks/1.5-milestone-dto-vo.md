# 1.5: Milestone DTOs, VOs, and MainItem extension

## Description
Create MilestoneMap and Milestone DTOs (request/response/filter types) and VOs (view objects with enrichment fields). Extend MainItem DTOs (MainItemFilter, MainItemCreateReq, MainItemUpdateReq) and MainItemVO with milestone-related fields.

## Reference Files
- docs/features/milestone-map/design/tech-design.md — DTO Definitions (Milestone DTOs NEW, MainItem DTOs MODIFIED), VO Definitions (Milestone VOs NEW, MainItemVO MODIFIED), Cross-Layer Data Map
- docs/features/milestone-map/design/api-handbook.md — Request/Response field definitions

## Acceptance Criteria
- [ ] MilestoneMap DTOs (`MilestoneMapCreateReq`, `MilestoneMapUpdateReq`, `MilestoneMapFilter`) in `dto/milestone_dto.go` match api-handbook field names, types, and validation tags
- [ ] Milestone DTOs (`MilestoneCreateReq`, `MilestoneUpdateReq`, `MilestoneTeamFilter`) match api-handbook field definitions
- [ ] `MainItemFilter` updated with `MilestoneKey *string` field; `MainItemCreateReq` with `MilestoneKey *string`; `MainItemUpdateReq` with `MilestoneKey *string` (nil=no change, empty string=unbind)
- [ ] `MilestoneMapVO` and `MilestoneVO` in `vo/milestone_vo.go` include all fields from tech-design (computed fields: MilestoneCount, ItemCount, OverallProgress, Completion, RelatedMICount)
- [ ] `MainItemVO` updated with `MilestoneKey *string` and `MilestoneName string` fields
