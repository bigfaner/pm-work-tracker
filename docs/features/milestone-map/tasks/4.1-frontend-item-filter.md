# 4.1: Item view page milestone filter (UF-4)

## Description
Integrate milestone filter dropdown into the existing ItemViewPage filter bar and add milestone name badges to MI list items. This is an integration task on the existing `/items` page.

## Reference Files
- docs/features/milestone-map/ui/ui-design.md — Component: 事项清单页里程碑筛选（UF-4）
- docs/features/milestone-map/design/tech-design.md — Integration: MilestoneFilter → ItemViewPage (UF-4)
- docs/features/milestone-map/prd/prd-ui-functions.md — UF-4
- frontend/src/pages/item-view/ — target page files

## Acceptance Criteria
- [ ] Milestone filter `Select` renders in ItemViewPage filter bar, positioned right of existing `MemberSelect`; loads options from `listMilestonesByTeam({excludeCancelled: true})` with "全部" + "未分配" options
- [ ] Selecting a milestone filters MI list by passing `milestoneKey` to MainItemFilter; "未分配" filters for `milestoneKey=null`; "全部" shows all (default)
- [ ] Each MI with non-null milestoneKey displays milestone name as a `Badge` (rounded-full, text-xs); unassigned MIs show no badge
- [ ] Filter resets to "全部" on team switch; options refresh for new team
- [ ] API failure on milestone options: dropdown shows "加载失败" and disables; other filter components unaffected
