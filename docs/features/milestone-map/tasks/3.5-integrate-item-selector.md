# 3.5: Integrate: Item Edit Milestone Selector (UF-5)

## Description

Add "所属里程碑" dropdown selector to the main item edit dialog. Positioned below the "负责人" field. Options exclude cancelled milestones. Allows binding, rebinding, or unbinding a MI to a milestone.

## Reference Files

- `design/tech-design.md` — Integration Spec: MilestoneSelector → /items/:mainItemId page (UF-5)
- `ui/ui-design.md` — Component "主事项编辑弹窗里程碑选择器" (UF-5)
- `ui/prototype/item-detail.html` — Prototype with milestone selector
- `frontend/src/components/CreateMainItemDialog/` — Target component
- `prd/prd-ui-functions.md` — UF-5 specification

## Acceptance Criteria

- [ ] "所属里程碑" dropdown added to CreateMainItemDialog, below "负责人" field
- [ ] Dropdown options: all team milestones (excluding cancelled) + "未分配" (default for new items)
- [ ] Existing MI edit: pre-fills current milestoneKey, allows change or clear
- [ ] New MI create: defaults to "未分配"
- [ ] Saving with milestone set calls `createMainItemApi`/`updateMainItemApi` with milestoneKey
- [ ] When team has 0 milestones, dropdown only shows "未分配"
- [ ] Component works correctly in isolation (build task)

## User Stories

- Story 6: "在主事项编辑页选择一个里程碑 → MI 的 milestone_key 设为该里程碑的 bizKey"
- Story 6: "清空里程碑字段 → MI 的 milestone_key 置空"
- Story 6: "团队下没有创建任何里程碑 → 下拉框仅显示'未分配'选项"

## Implementation Notes

- Integration task: add the selector to the existing dialog component
- Data source: `listMilestonesByTeamApi(teamBizKey, { excludeCancelled: true })`
- milestoneKey passed as string (bizKey format) or null/empty for unassigned
