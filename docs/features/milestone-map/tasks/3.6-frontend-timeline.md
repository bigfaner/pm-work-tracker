# 3.6: Timeline view and node components (UF-1 level 2)

## Description
Build MilestoneTimeline and MilestoneNode components for the timeline view (UF-1 second level). Implements date-proportional node positioning, zoom controls (week/month/quarter), filtering, drag-and-drop MI rebinding, and breadcrumb navigation.

## Reference Files
- docs/features/milestone-map/ui/ui-design.md — Component: 里程碑时间线视图（UF-1 第二级）, Timeline Layout Algorithm, Keyboard Navigation
- docs/features/milestone-map/ui/prototype/milestone-detail.html — interactive prototype
- docs/features/milestone-map/prd/prd-ui-functions.md — UF-1 time line view Data Requirements, Interactions

## Acceptance Criteria
- [ ] Timeline renders milestone nodes positioned by expected_end_date (`x = (date - origin) / totalDays * containerWidth`), each showing status dot, name, completion %, date, MI count; `minWidth = nodeCount * 184` triggers horizontal scroll when needed
- [ ] Zoom controls (week=7d / month=30d / quarter=90d) change tick mark density (vertical lines + labels) without moving nodes; transition 200ms
- [ ] Name search (debounce 300ms) and StatusTagFilter (multi-select toggle) filter milestone nodes; reset + refresh buttons work
- [ ] Click milestone node opens detail panel (3.4); click MI item navigates to `/items/:mainItemId`; breadcrumb "里程碑图" returns to list
- [ ] Drag MI to another milestone: API update + opacity-50 during drag + target highlight + undo toast (5s) on completion

## User Stories
- Story 9 (时间线视图部分): PM 通过里程碑图查看阶段进展
