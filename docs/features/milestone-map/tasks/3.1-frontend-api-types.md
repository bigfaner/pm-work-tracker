# 3.1: Frontend API Client + Types

## Description

Create TypeScript types for MilestoneMap and Milestone, API client functions for all milestone endpoints, and update MainItem type with milestoneKey/milestoneName fields.

## Reference Files

- `design/api-handbook.md` — All endpoint specs
- `design/tech-design.md` — Cross-Layer Data Map (field types at frontend layer)
- `frontend/src/api/mainItems.ts` — API client pattern
- `frontend/src/api/client.ts` — Base client setup
- `frontend/src/types/index.ts` — Type definitions pattern

## Acceptance Criteria

- [ ] `types/index.ts`: MilestoneMap interface (bizKey, teamKey, mapName, mapDesc, mapStatus, statusName, milestoneCount, itemCount, overallProgress, createTime, dbUpdateTime)
- [ ] `types/index.ts`: Milestone interface (bizKey, teamKey, milestoneMapKey, milestoneName, expectedEndDate, milestoneStatus, statusName, completion, relatedMICount, createTime, dbUpdateTime)
- [ ] `types/index.ts`: CreateMilestoneMapReq, UpdateMilestoneMapReq, CreateMilestoneReq, UpdateMilestoneReq, MilestoneMapFilter
- [ ] `types/index.ts`: MainItem type gains `milestoneKey: string | null` and `milestoneName?: string`
- [ ] `api/milestones.ts`: All 14 API functions (7 MilestoneMap + 7 Milestone endpoints)
- [ ] All API functions use correct HTTP methods, paths, and return types
- [ ] `npm test` passes (no type errors)

## User Stories

No direct user story — foundational frontend layer.

## Implementation Notes

- Follow exact pattern from `api/mainItems.ts`: import client, use `client.<method><NeverType, ReturnType>(url, ...)`
- API paths: `/teams/${teamBizKey}/milestone-maps/...` and `/teams/${teamBizKey}/milestones/...`
- BizKey params passed as strings (matching `FormatID` output from backend)
