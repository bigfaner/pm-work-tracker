# 3.1: Frontend API module, types, and status utilities

## Description
Create the milestones API module (`src/api/milestones.ts`) with all 14 API functions, add MilestoneMap and Milestone TypeScript interfaces to `src/types/index.ts`, and add status variant mappings to `src/utils/status.ts`.

## Reference Files
- docs/features/milestone-map/ui/ui-design.md — API Module (NEW), Types (MODIFIED), Status Badge 颜色映射
- docs/features/milestone-map/design/api-handbook.md — all endpoint definitions
- frontend/src/api/mainItems.ts — API module pattern reference
- frontend/src/types/index.ts — existing type definitions

## Acceptance Criteria
- [ ] `milestones.ts` exports all 14 API functions (7 MilestoneMap + 7 Milestone) matching api-handbook HTTP methods, paths, and parameter shapes
- [ ] `MilestoneMap` and `Milestone` TypeScript interfaces in `types/index.ts` match backend VO field lists (including computed: milestoneCount, itemCount, overallProgress, completion, relatedMICount)
- [ ] Status variant mappings added in `status.ts` for MilestoneMap (6 states: planning→neutral, reviewed→warning, ready→warning, executing→info, completed→success, cancelled→error) and Milestone (4 states: not_started→neutral, in_progress→info, completed→success, cancelled→error)
- [ ] All API functions use shared `client` instance and `getTeamId()` from Zustand store
