# 2.2: Milestone repository (interface + GORM implementation)

## Description
Implement the MilestoneRepo interface and its GORM implementation for Milestone CRUD, listing by map/team, soft delete (single and batch by map), batch bizKey lookup, and name uniqueness checking.

## Reference Files
- docs/features/milestone-map/design/tech-design.md — Interfaces (MilestoneRepo), Architecture Layer Placement
- backend/internal/repository/gorm/ — existing repo implementations for pattern reference

## Acceptance Criteria
- [ ] `MilestoneRepo` interface in `repository/milestone_repo.go` defines all 9 methods: Create, FindByID, FindByBizKey, FindBatchByBizKeys, Update, ListByMap, ListByTeam, SoftDelete, SoftDeleteByMap, ExistsByNameAndMap
- [ ] `Create` persists Milestone with correct field mapping and generates BizKey via snowflake
- [ ] `ListByMap` returns all non-deleted milestones for a map, sorted by `expected_end_date` ascending
- [ ] `ListByTeam` with filter (name, status, excludeCancelled) returns filtered milestones
- [ ] `SoftDeleteByMap` soft-deletes all milestones under a given map ID
- [ ] `ExistsByNameAndMap` returns true when a non-deleted milestone with the same name exists in the same map (supports excludeID for edit)
