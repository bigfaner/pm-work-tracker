# 3.3: Build: Milestone Detail Panel + Dialogs (UF-2, UF-3, UF-3a)

## Description

Build the milestone detail panel (UF-3) with status badge switching, inline × unbind, and "+ 添加" button. Build the create/edit milestone dialog (UF-2) and quick-add MI dialog (UF-3a, reusing CreateMainItemDialog with milestone pre-filled).

## Reference Files

- `ui/ui-design.md` — Component "里程碑详情面板" (UF-3), "创建/编辑里程碑弹窗" (UF-2), "Quick Add MainItem Dialog" (UF-3a)
- `ui/prototype/milestones.html` — Detail panel, create milestone modal, add-MI modal
- `design/tech-design.md` — Integration Specs, Interfaces
- `design/api-handbook.md` — Milestone endpoints

## Acceptance Criteria

- [ ] Detail panel (UF-3): slides in from right, shows milestone name, expectedEndDate, status badge (clickable dropdown), completion bar, edit button, delete button
- [ ] Detail panel: inline meta row (date + status badge + edit button) at same height
- [ ] Detail panel: related MI list with each row showing MI info + × unbind button
- [ ] × unbind button: calls `updateMainItemApi` with milestoneKey=null, shows undo toast, refreshes list
- [ ] "+ 添加" button: inline on same row as "关联事项" heading
- [ ] Create/edit milestone dialog (UF-2): milestoneName + expectedEndDate fields, validation
- [ ] Quick-add MI dialog (UF-3a): reuses CreateMainItemDialog form, milestoneKey pre-filled and disabled
- [ ] Status badge dropdown: shows available transitions from API, changes status on select
- [ ] Cancelled milestones: greyed-out style, empty MI list
- [ ] `npm test` passes for new components

## User Stories

- Story 4a: PM 创建里程碑 (UF-2 create mode)
- Story 4b: PM 编辑里程碑 (UF-2 edit mode)
- Story 4c: PM 删除里程碑 (delete button in panel)
- Story 5: PM 切换里程碑状态 (badge dropdown in panel)
- Story 7: 详情面板管理事项 (panel + inline unbind + quick add)
- Story 7: 行内解绑 (× button on MI row)

## Implementation Notes

- UF-3a reuses existing `CreateMainItemDialog` component, passing milestoneKey as prop with `disabled: true`
- Unbind via MainItem update API (not a dedicated unbind endpoint)
- Status dropdown data from `getMilestoneTransitionsApi` or `getMilestoneMapTransitionsApi`
