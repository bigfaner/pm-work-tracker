# 4.2: Edit main item dialog milestone selector (UF-5)

## Description
Add "所属里程碑" Select dropdown to the existing EditMainItemDialog, positioned below the "负责人" field. Loads milestone options and saves milestoneKey with the main item update.

- docs/features/milestone-map/ui/ui-design.md — Component: 主事项编辑弹窗里程碑选择器（UF-5）
- docs/features/milestone-map/design/tech-design.md — Integration: MilestoneSelector → EditMainItemDialog (UF-5)
- docs/features/milestone-map/prd/prd-ui-functions.md — UF-5
- frontend/src/pages/item-view/ or frontend/src/pages/main-item-detail/ — EditMainItemDialog location

## Acceptance Criteria
- [ ] "所属里程碑" `Select` renders in EditMainItemDialog below "负责人" field; loads options from `listMilestonesByTeam({excludeCancelled: true})` with "未分配" + milestone names
- [ ] Pre-fills current value when dialog opens (milestone name or "未分配"); "未分配" sends `milestoneKey: null` on save
- [ ] Save updates MI `milestoneKey` via update API; no change if unmodified
- [ ] Cancelled milestones excluded from options; no milestones in team → only "未分配" option; API failure shows "加载失败" and disables select
