# 2.1: MilestoneMap Repo + Service + Handler + Routes

## Description

Implement the full MilestoneMap backend stack: GORM repository, service layer (with computed fields and status transitions), HTTP handlers, and route registration.

## Reference Files

- `design/tech-design.md` — MilestoneMapRepo, MilestoneMapService interfaces; Computed Fields
- `design/api-handbook.md` — All MilestoneMap endpoints (Create, List, Get, Update, Delete, ChangeStatus, AvailableTransitions)
- `backend/internal/repository/main_item_repo.go` — Repo interface pattern
- `backend/internal/repository/gorm/main_item_repo.go` — GORM implementation pattern
- `backend/internal/service/main_item_service.go` — Service pattern (bizKey boundary, snowflake generation)
- `backend/internal/handler/main_item_handler.go` — Handler pattern (BizKey param parsing, VO conversion)
- `backend/internal/handler/router.go` — Route registration pattern

## Acceptance Criteria

- [ ] `repository/milestone_map_repo.go`: Interface with Create, FindByID, FindByBizKey, Update, List (paginated), SoftDelete
- [ ] `repository/gorm/milestone_map_repo.go`: GORM implementation with team-scoped queries, status filter
- [ ] `service/milestone_map_service.go`: Interface + implementation with Create, Update, Get, GetByBizKey, List, Delete (cascade soft-delete milestones + unbind MIs), ChangeStatus, AvailableTransitions, calcOverallProgress
- [ ] `handler/milestone_map_handler.go`: Create, List, Get, Update, Delete, ChangeStatus, AvailableTransitions handlers
- [ ] `handler/router.go`: 7 routes registered under teams group with milestone:create/read/update/delete permissions
- [ ] Delete endpoint cascades: soft-deletes map + soft-deletes all milestones + unbinds all MIs in one transaction
- [ ] List returns computed fields (milestoneCount, itemCount, overallProgress) per map
- [ ] `just test` passes for all new code

## User Stories

- Story 1: PM 创建里程碑图 (name 1-100 chars, default status planning)
- Story 2: PM 编辑里程碑图信息
- Story 3: PM 切换里程碑图状态 (5-state transition)
- Story 8: 里程碑图列表 + 状态筛选 + 整体进度
- Story 11: 管理层只读查看列表

## Implementation Notes

- calcOverallProgress: `SELECT AVG(completion_pct) FROM pmw_main_items WHERE milestone_key IN (SELECT biz_key FROM pmw_milestones WHERE milestone_map_key = ? AND deleted_flag = 0) AND deleted_flag = 0`
- calcMilestoneCount: count milestones where milestone_map_key = map's bizKey and deleted_flag = 0
- calcItemCount: count main_items where milestone_key IN (milestones of this map) and deleted_flag = 0
- Delete cascade: call MilestoneRepo.DeleteByMap in the same transaction as SoftDelete
