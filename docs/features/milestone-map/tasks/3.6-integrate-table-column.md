## Description

Add "里程碑" column to the table view (/table). Shows milestone name per MI, supports sorting and filtering by milestone.

## Acceptance Criteria

- [ ] "里程碑" column added between "标题" and "优先级" columns
- [ ] Shows milestone name for assigned MIs, "-" for unassigned, "--" for soft-deleted milestones
- [ ] Column supports ascending/descending sort (default ascending by milestone name)
- [ ] Unassigned MIs sort to the end
- [ ] Column header supports filter dropdown: all milestones + "全部" + "未分配"
- [ ] Component works correctly in isolation (build task)

- Story 10: "表格增加'里程碑'列，显示 MI 所属里程碑名称"
