# 2.2c: Milestone Complex Operations

## Description

Implement the complex Milestone operations: Delete (transaction with MI unbinding), ChangeStatus (cancelled auto-unbinds), AvailableTransitions, and computed fields (completion, relatedMICount).

## Reference Files

- `design/api-handbook.md` — Delete, ChangeStatus, AvailableTransitions endpoints
- `design/tech-design.md` — Computed Fields, status transition rules
- `backend/internal/pkg/repo/transactor.go` — Transaction pattern

## Acceptance Criteria

- [ ] Delete: soft-delete milestone + unbind all associated MIs (SET milestone_key = NULL) in one transaction
- [ ] ChangeStatus: 4-state transition (not_started→in_progress→completed, cancelled from any non-terminal)
- [ ] Special: ChangeStatus to `cancelled` auto-unbinds all associated MIs
- [ ] AvailableTransitions: return valid next states for current milestone status
- [ ] calcCompletion: `SELECT AVG(completion_pct) FROM pmw_main_items WHERE milestone_key = ? AND deleted_flag = 0` → return 0 if no rows
- [ ] countRelatedMIs: count main_items where milestone_key = milestone's bizKey and deleted_flag = 0
- [ ] Routes: DELETE, PUT status, GET available-transitions
- [ ] `just test` passes

## Implementation Notes

- Delete transaction: use DBTransactor. In one tx: SoftDelete milestone, then UPDATE main_items SET milestone_key = NULL WHERE milestone_key = ?
- Status states: not_started, in_progress, completed (terminal), cancelled (terminal)
- Cancelled auto-unbind: same as Delete but keeps the milestone record (soft-deleted status, not soft-deleted record)
- calcCompletion: return 0 for milestones with no MIs (AVG returns NULL for empty set)
