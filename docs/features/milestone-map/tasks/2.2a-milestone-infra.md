## Implementation Notes

- FindByBizKeys is critical for MainItem list enrichment (batch lookup, not N+1)
- ListByMap: filter by milestone_map_key, exclude deleted, order by expected_end_date ASC
- ListByTeam: filter by team_key, exclude deleted, optional excludeCancelled filter
- DeleteByMap: soft-delete all milestones where milestone_map_key = given bizKey (used by MilestoneMap cascade delete)
- acceptedFields: add `model.Milestone{}.TableName()` → {milestone_name, expected_end_date, milestone_status} fields
