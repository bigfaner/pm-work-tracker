# 3.3: Create/Edit Milestone dialog component (UF-2)

## Description
Build the CreateMilestoneDialog component for creating and editing milestones within a milestone map. Uses Dialog, Input, Textarea, and date picker components.

## Reference Files
- docs/features/milestone-map/ui/ui-design.md — Component: 创建/编辑里程碑弹窗（UF-2）
- docs/features/milestone-map/ui/prototype/milestones.html — interactive prototype
- docs/features/milestone-map/design/tech-design.md — DTO Definitions (MilestoneCreateReq, MilestoneUpdateReq)
- frontend/src/components/ui/dialog.tsx — Dialog component

## Acceptance Criteria
- [ ] Dialog renders form with name (Input, required 1-100 chars), expected end date (DatePicker, required), description (Textarea, optional)
- [ ] Create mode: title "创建里程碑", empty form; validation enforces name + expected end date required; on success calls `createMilestone` API
- [ ] Edit mode: title "编辑里程碑", form pre-fills current milestone values; on success calls `updateMilestone` API
- [ ] Submitting state: confirm button shows loading, all inputs disabled

## User Stories
- Story 5: PM 创建里程碑 (create mode)
- Story 6: PM 编辑里程碑信息 (edit mode)
