里程碑图原型导航

以下是里程碑图功能的 HTML 原型页面。每个页面展示了不同 UI Function 的交互效果，包含可点击的弹窗、面板、下拉框等组件。

里程碑时间线

主时间线页面，包含横向时间轴、里程碑节点、关联事项展示。支持创建弹窗(UF-2)、详情面板(UF-3)、删除确认、撤销 Toast、多状态切换预览。

事项清单（含里程碑筛选）

事项列表页新增里程碑筛选下拉框，支持按里程碑过滤事项。事项条目旁显示里程碑名称标签。

UF-4

事项详情（含里程碑选择器）

事项详情页的编辑弹窗中新增"所属里程碑"下拉选择器，支持分配/取消分配里程碑。

UF-5

表格视图（含里程碑列）

表格视图新增"里程碑"列，显示已分配的里程碑名称或"-"。支持列头排序和筛选。
