# 2.2: Team handler: remove PM BizKey substitution and isSuperAdmin checks

## Description

Remove all SuperAdmin-specific logic from `team_handler.go`:
- 5 endpoints that substitute SuperAdmin's BizKey with team.PmKey (Update, Disband, RemoveMember, UpdateMemberRole, TransferPM)
- List endpoint's `isSuperAdmin` parameter removal
- All `IsSuperAdmin(c)` conditionals in this handler

Call the simplified TeamService signatures from 2.1 directly — no pmBizKey arguments needed.

## Reference Files

- `design/tech-design.md` — Interface 4 + PRD 5.3 items 3-8
- `backend/internal/handler/team_handler.go` — 6 endpoints with SuperAdmin logic
- `backend/internal/service/team_service.go` — simplified signatures (from 2.1)

## Acceptance Criteria

- [ ] No `IsSuperAdmin` references in team_handler.go
- [ ] No `pmBizKey` or `callerBizKey` variables in handler methods
- [ ] No `team.PmKey` access for authorization purposes
- [ ] All 6 endpoints call simplified service methods
- [ ] Backend compiles: `cd backend && go build ./...`
- [ ] Handler tests pass: `cd backend && go test ./internal/handler/...`

## User Stories

- Story 3 (AC3a): SuperAdmin team ops — middleware passes via all 29 codes, handler has no special path
- Story 6: PM ops — handler calls simplified service, middleware enforces permission codes

## Implementation Notes

Each of the 5 endpoints (Update L99, Disband L128, RemoveMember L194, UpdateMemberRole L233, TransferPM L276) has a pattern like:
```go
if middleware.IsSuperAdmin(c) { pmBizKey = team.PmKey }
```
Remove these blocks and the `pmBizKey` variable entirely. Call service methods without the pmBizKey arg.
