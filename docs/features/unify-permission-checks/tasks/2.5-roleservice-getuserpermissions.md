# 2.5: RoleService: GetUserPermissions SuperAdmin path + remove IsSuperAdmin

## Description

Two changes in `role_service.go`:
1. Remove `IsSuperAdmin` field from `UserPermissions` struct (and any related DTOs)
2. Add SuperAdmin path to `GetUserPermissions`: when `user.IsSuperAdmin == true`, return all 29 codes for all teams instead of querying `GetUserTeamPermissions`. This requires adding `teamRepo.ListTeamBizKeys(ctx)` dependency.

Add `ListTeamBizKeys(ctx context.Context) ([]int64, error)` to the teamRepo interface.

## Reference Files

- `design/tech-design.md` — Interface 3: RoleService.GetUserPermissions — Modified
- `backend/internal/service/role_service.go` — `UserPermissions` struct, `GetUserPermissions` method
- `backend/internal/repository/gorm/team_repo.go` — add `ListTeamBizKeys` implementation

## Implementation Notes

The `GetUserPermissions` SuperAdmin path needs `teamRepo` as a new dependency. The repo interface addition `ListTeamBizKeys` returns `[]int64` (team IDs/bizkeys). When no teams exist (fresh system), returns empty map — this is correct (see tech-design edge case section).
