# 2.1: TeamService: simplify signatures, remove PM identity checks

## Description

Remove `pmBizKey`/`callerBizKey` parameters from TeamService methods and remove all `team.PmKey != pmBizKey` checks. Authorization is now enforced by `RequirePermission` middleware — the service layer no longer needs to verify PM identity.

Simplified signatures:
- `UpdateTeam(ctx, teamBizKey, req)` (was: `ctx, pmBizKey, teamBizKey, req`)
- `RemoveMember(ctx, teamBizKey, targetUserBizKey)` (was: `ctx, pmBizKey, ...`)
- `TransferPM(ctx, teamBizKey, newPMBizKey)` (was: `ctx, currentPMBizKey, ...`)
- `DisbandTeam(ctx, teamBizKey, confirmName)` (was: `ctx, callerBizKey, ...`)
- `UpdateMemberRole(ctx, targetUserBizKey, teamBizKey, roleBizKey)` (was: `ctx, pmBizKey, ...`)
- `ListTeams(ctx, search, page, pageSize)` (was: `ctx, callerID, isSuperAdmin, ...`)

Also remove `isPMRole()` helper — inline `role.Name == "pm"` comparison in `InviteMember` for the PM-role business rule.
