# 1.2: RequirePermission: remove SuperAdmin tier-1 bypass

## Description

Remove the SuperAdmin short-circuit from `RequirePermission` middleware in `middleware/permission.go`. Delete the `if IsSuperAdmin(c) { c.Next(); return }` block. All users now pass through permCodes check uniformly. SuperAdmin passes because TeamScopeMiddleware (1.3) injects all 29 codes.
