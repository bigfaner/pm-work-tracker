# 2.4: Progress handler: rename pmFlag, source skipRegressionCheck from permCode

## Description

In `progress_handler.go`, replace `pmFlag := isPMOrSuperAdmin(c)` with `skipRegressionCheck := hasPermCode(c, "sub_item:assign")`. Remove the `isPMOrSuperAdmin()` call. Update `progress_service.go` to rename the `isPM bool` parameter to `skipRegressionCheck bool`. The behavior is identical: PM and SuperAdmin (who have `sub_item:assign` via all 29 codes) skip regression check; others don't.
