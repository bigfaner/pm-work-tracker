# 3.1: Frontend source: remove isSuperAdmin from types, store, page, mocks

## Description

Remove all `isSuperAdmin` references from frontend production source files:
1. `src/types/index.ts` — remove `isSuperAdmin: boolean` from `UserInfo`, `PermissionsResponse`, `LoginResponse`, and the 4th interface (4 occurrences)
2. `src/store/auth.ts` — remove state field, setter, login handler assignment, and `hasPermission` bypass (`if permissions.isSuperAdmin return true`)
3. `src/pages/UserManagementPage.tsx` — replace `const isSuperAdmin = useAuthStore(...)` with `hasPermission("user:manage_role")` or equivalent
4. `src/mocks/handlers.ts` — remove `isSuperAdmin` from mock response fixture

## Implementation Notes

The `hasPermission` bypass in `store/auth.ts` (`if permissions.isSuperAdmin return true`) must be removed. After this, `hasPermission()` relies solely on the permission codes returned by `/me/permissions`. Since SuperAdmin now gets all 29 codes (task 2.5), `hasPermission()` returns true for everything — no bypass needed.
