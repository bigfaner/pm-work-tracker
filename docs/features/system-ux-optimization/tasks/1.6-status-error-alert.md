# 1.6: 状态流转错误提示

## Description
StatusTransitionDropdown 将 2 秒 tooltip 替换为持久 Alert 行内错误消息。消息来自后端 422 响应体。Alert 不自动消失，支持手动关闭，再次流转时更新。

- docs/features/system-ux-optimization/design/tech-design.md — Interface 11: 前端组件接口变更（#1）
- docs/features/system-ux-optimization/prd/prd-ui-functions.md — UI Function 1: 状态流转错误提示

## Acceptance Criteria
- [ ] 1. 状态流转失败时展示 Alert 行内错误消息，内容为后端返回的具体原因
- [ ] 2. Alert 不自动消失
- [ ] 3. 手动关闭 Alert 后隐藏
- [ ] 4. 再次点击流转按钮时 Alert 更新或清除
- [ ] 5. 流转成功时 Alert 消失
