# 1.8: 每周进展过滤

## Description
ViewService.WeeklyComparison 增加过滤逻辑：隐藏终态且本周/上周都无活跃子事项的主事项。新增 StatusHistoryRepo.ListByItemKeysInRange 方法。

## Reference Files
- docs/features/system-ux-optimization/design/tech-design.md — Interface 8: 每周进展过滤（#16）

## Acceptance Criteria
- [ ] 1. 终态主事项 + 本周/上周都无活跃子事项 → 隐藏
- [ ] 2. 终态主事项 + 本周有活跃子事项 → 展示
- [ ] 3. 非终态主事项 → 始终展示

## User Stories
Story 11 (团队选择器和每周进展过滤)

## Hard Rules
活跃子事项判断需使用 status_history + sub_item created_at/updated_at

## Implementation Notes
- Affected files: `backend/internal/service/view_service.go`, `backend/internal/repository/status_history_repo.go`
