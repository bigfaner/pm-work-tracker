# 1.4: 删除功能

## Description
新增 DELETE /main-items/:itemId 和 DELETE /sub-items/:subId 端点。新增 main_item:delete 和 sub_item:delete 权限码。主事项删除级联软删除所有子事项，在单个事务内执行。记录 status_histories 审计日志。

## Reference Files
- docs/features/system-ux-optimization/design/tech-design.md — Interface 1: 删除主事项, Interface 2: 删除子事项
- docs/features/system-ux-optimization/design/api-handbook.md — Delete Main Item, Delete Sub Item

## Acceptance Criteria
- [ ] 1. PM 用户可 DELETE 主事项，所有子事项一并软删除，item_status 不变
- [ ] 2. PM 用户可 DELETE 子事项，父主事项 completion_pct 重算
- [ ] 3. 无权限用户返回 403
- [ ] 4. 不存在事项返回 404
- [ ] 5. seed 数据包含 main_item:delete 和 sub_item:delete 权限码

## User Stories
Story 3 (删除事项)

## Hard Rules
主事项删除须在单个事务内完成（级联软删除 + status_history 审计）
