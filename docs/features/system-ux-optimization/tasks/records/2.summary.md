## Conventions Established

- Multi-status query params serialized as repeated `?status=a&status=b` (axios paramsSerializer) for Gantt, comma-separated string for main item list — backend handles both patterns.
- Filter penetration pattern: Service-layer memory-based filtering with match metadata returned alongside PageResult for clean separation.
- Terminal sort applied as post-processing step via sort.SliceStable, reusable across List and GanttView paths.
- CSS-only fixes for platform-specific scrollbar issues using webkit-scrollbar pseudo-elements with hover-visible pattern.
- Frontend reuses existing CheckboxGroup and ConfirmDialog components rather than building new primitives.
