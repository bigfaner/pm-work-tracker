# 1.5: 转换表单优化

## Description
三部分优化：(a) 待办→子事项描述字段置灰 disabled；(b) 负责人和优先级必填校验，未填时提交禁用；(c) 表单关闭/提交成功时清空所有字段。

## Reference Files
- docs/features/system-ux-optimization/design/tech-design.md — Interface 11: 前端组件接口变更（#4,#6,#7）
- docs/features/system-ux-optimization/prd/prd-ui-functions.md — UI Function 4: 转换表单优化

## Acceptance Criteria
- [ ] 1. 待办→子事项转换表单描述字段为 disabled 灰色样式
- [ ] 2. 未选负责人或优先级时提交按钮禁用，标签显示 * 标记
- [ ] 3. 提交成功或关闭表单后，所有字段清空
- [ ] 4. 提交失败时字段保留不清空

Story 4 (转换表单交互优化)
