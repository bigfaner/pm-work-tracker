# 2.8: 删除和移动前端 UI

## Description
前端新增删除按钮（PermissionGuard 包裹，确认对话框含子事项数量）和移动按钮（目标主事项选择器，确认对话框）。

## Reference Files
- docs/features/system-ux-optimization/design/tech-design.md — Integration: DeleteButton, MoveSubItemButton
- docs/features/system-ux-optimization/prd/prd-ui-functions.md — UI Function 3: 事项删除, UI Function 6: 子事项移动

## Acceptance Criteria
- [ ] 1. 主事项详情页展示删除按钮（PM 角色），确认对话框含子事项数量
- [ ] 2. 子事项详情页展示删除按钮（PM 角色）
- [ ] 3. 删除成功后页面更新
- [ ] 4. 子事项详情页展示移动按钮
- [ ] 5. 移动对话框选择目标主事项（排除已关闭和当前主事项）
- [ ] 6. 移动成功后页面更新

## User Stories
Story 3 (删除事项), Story 7 (移动子事项)

## Implementation Notes
- Affected files: main-item-detail page, sub-item-detail page, new API functions in frontend/src/api/
