# 2.1: 移动子事项

## Description
新增 PUT /sub-items/:subId/move 端点。事务内原子自增目标 sub_item_seq，重新生成编号。校验目标非终态、非同一主事项、同团队。

- docs/features/system-ux-optimization/design/tech-design.md — Interface 3: 移动子事项

## Acceptance Criteria
- [ ] 1. 移动后子事项归属目标主事项，编号自动更新
- [ ] 2. 状态和负责人不变
- [ ] 3. 已关闭目标返回 400
- [ ] 4. 同一主事项返回 400
- [ ] 5. 跨团队目标返回错误
- [ ] 6. 源和目标主事项 completion_pct 重算
